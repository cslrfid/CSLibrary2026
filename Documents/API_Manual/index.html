CSLibrary2026 API Reference

The application programming interface of the CSL RFID reader library.

This manual documents the API that an application uses to talk to a CSL RFID reader. It is written for the application developer: everything that is needed to write an application is here, and nothing about the protocol, the chipset or the transport that the library uses internally.

The reader is reached through one object, HighLevelInterface. Its properties give access to the subsystems of the reader, and the same API works for every reader model and for every connection type.

The object model

HighLevelInterface
├── .rfid           RFIDReader    inventory, tag access, singulation, power, antenna ports
├── .barcode        BarcodeReader the barcode scanner
├── .notification   Notification  battery voltage and hardware keys
├── .battery        Battery       the battery level and the polling interval
├── .bluetoothIC    BluetoothIC   the Bluetooth name and firmware version
├── .siliconlabIC   SiliconLabIC  the reader hardware and firmware information
└── .Options        CSLibraryOperationParms  the configuration of the radio
