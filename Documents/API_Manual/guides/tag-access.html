CSLibrary2026 API Reference

Reading and writing a tag

Addressing a single tag: reading, writing, locking and killing.

The target tag

The tag that an operation applies to is selected with the select criteria or with a tag group. Both are set before the operation is started.

// Select by the EPC of the tag.
reader.rfid.SetSelectCriteria(new SelectCriterion[]
{
    new SelectCriterion
    {
        Criterion = SelectFlags.SELECT,
        Target = Target.SELECT_A,
        Mask = SelectMask.EPC,
        Data = new SelectData { EPC = "300833B234DD5F1903718B9B0F0" }
    }
});

// Or select a whole group of tags.
reader.rfid.SetTagGroup(TagGroup.SL_ALL);

CancelAllSelectCriteria() removes the criteria again.

Reading a tag

reader.rfid.Options.TagReadUser.bank = MemoryBank.USER;
reader.rfid.Options.TagReadUser.offset = 0;
reader.rfid.Options.TagReadUser.count = 4;
reader.rfid.Options.TagReadUser.accessPassword = 0;

reader.rfid.StartOperation(Operation.TAG_READ);

The result is delivered through OnAccessCompleted.

reader.rfid.OnAccessCompleted += (sender, e) =>
{
    if (!e.success)
        return;

    if (e.bank == MemoryBank.USER)
    {
        IBANK data = e.data;
        Console.WriteLine($"Read {data.length} words from the USER bank");
    }
};

Writing a tag

reader.rfid.Options.TagWriteUser.bank = MemoryBank.USER;
reader.rfid.Options.TagWriteUser.offset = 0;
reader.rfid.Options.TagWriteUser.count = 2;
reader.rfid.Options.TagWriteUser.pData = new ushort[] { 0x1234, 0x5678 };
reader.rfid.Options.TagWriteUser.accessPassword = 0;

reader.rfid.StartOperation(Operation.TAG_WRITE);

Locking and killing a tag

reader.rfid.Options.TagLock.lockAction = TagLockAction.LOCK;
reader.rfid.StartOperation(Operation.TAG_LOCK);

reader.rfid.Options.TagKill.killPassword = 0x12345678;
reader.rfid.StartOperation(Operation.TAG_KILL);

Killing a tag is permanent: the tag stops responding to every read afterwards. The kill password of the tag must be known to the application.

The access result

MemberDescription
bool successWhether the operation succeeded.
Bank bankThe memory bank that the operation applied to.
TagAccess accessThe operation that was performed: read, write, lock or kill.
IBANK dataThe data that was read. Only set for a read operation.

See Event reference and Tag access structures.
