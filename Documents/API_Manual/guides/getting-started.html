CSLibrary2026 API Reference

Getting started

Install the package, connect to a reader and run a first inventory.

Install the package

dotnet add package CSLibrary2026

The package supports .NET Standard 2.0, .NET Standard 2.1 and .NET 10, which covers Xamarin, .NET MAUI and .NET desktop applications.

Bluetooth LE on Windows. The net48 flavour of the library uses a different Bluetooth stack and is not published to NuGet. Build the library from source when your application targets .NET Framework 4.8.

Create a reader

One HighLevelInterface instance represents one reader connection. The subsystems of the reader are reached through its properties.

using CSLibrary;

var reader = new HighLevelInterface();

// The RFID radio.
RFIDReader rfid = reader.rfid;

// The barcode scanner, the notification handler and the battery monitor.
BarcodeReader barcode = reader.barcode;
Notification notification = reader.notification;
Battery battery = reader.battery;

Connect

Bluetooth LE and TCP/IP use the same object, only the connection call differs.

// Bluetooth LE
await reader.ConnectAsync(adapter, device, RFIDDEVICE.MODEL.CS108);

// TCP/IP
await reader.ConnectAsync("192.168.1.100", 2000);

See Device discovery for the details of the two connection methods and Connecting to a reader for the connection lifecycle.

Configure the radio

The reader is configured through reader.rfid.Options. The options must be set before an operation is started.

reader.rfid.Options.TagRanging.Multibanks = 2;
reader.rfid.Options.TagRanging.Bank1 = MemoryBank.USER;
reader.rfid.Options.TagRanging.Offset1 = 0;
reader.rfid.Options.TagRanging.Count1 = 1;

Receive the tags

The inventory callback is raised for every tag that the reader reads.

reader.rfid.OnAsyncCallback += (sender, e) =>
{
    if (e.type == CallbackType.TAG_RANGING)
    {
        TagCallbackInfo tag = e.info;
        Console.WriteLine($"{tag.epc.epcString}  {tag.rssi} dBm");
    }
};

Start and stop the inventory

reader.rfid.StartOperation(Operation.TAG_RANGING);

// ... the tags arrive through the callback ...

reader.rfid.StopOperation();

Disconnect

reader.DisconnectAsync();

See The connection lifecycle for the cleanup rules.
