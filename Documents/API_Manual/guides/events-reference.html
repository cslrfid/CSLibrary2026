CSLibrary2026 API Reference

Event reference

Every event of the library and the data that it delivers.

The reader events

EventDescription
HighLevelInterface.OnReaderStateChanged The connection state of the reader changed. The payload carries the new state and the reason.
RFIDReader.OnAsyncCallback A tag was read. The payload carries the tag information.
RFIDReader.OnAccessCompleted A tag access operation finished. The payload carries the result and the data that was read.
RFIDReader.OnStateChanged The state of the radio changed. The payload carries the new radio state.
RFIDReader.OnInventoryTagRateCallback The reader reports the number of tags that it reads per second.
RFIDReader.OnFM13DTAccessCompleted An FM13DT160 sensor operation finished.
Notification.OnVoltageEvent The battery voltage of the reader changed.
Notification.OnKeyEvent A hardware key of the reader was pressed or released.
BarcodeReader.OnCapturedNotify A barcode was scanned. The payload carries the barcode and its symbology.
BarcodeReader.OnStateChanged The state of the barcode scanner changed.

The inventory payload

OnAsyncCallbackEventArgs carries the tag information and the kind of the callback.

MemberDescription
CallbackType typeThe kind of the callback: TAG_RANGING or TAG_SEARCHING.
TagCallbackInfo infoThe tag that was read.

The tag information

MemberDescription
S_EPC epcThe electronic product code of the tag.
S_TID TIDThe tag identifier of the tag.
S_PC pcThe protocol control word of the tag.
S_XPC_W1 xpc_w1The first extended protocol control word.
float rssiThe signal strength of the tag, in dBm.
float rssidBmThe signal strength of the tag, in dBm, as reported by the reader.
uint antennaPortThe antenna port that read the tag.
uint freqChannelThe frequency channel that read the tag.
uint countThe number of reads of the tag in this inventory.
ushort[] Bank1DataThe data of the first requested memory bank.
ushort[] Bank2DataThe data of the second requested memory bank.
ushort[] Bank3DataThe data of the third requested memory bank.
DateTime receiveTimeThe time at which the reader read the tag.

The access payload

OnAccessCompletedEventArgs carries the result of a tag access operation.

MemberDescription
bool successWhether the operation succeeded.
Bank bankThe memory bank that the operation applied to.
TagAccess accessThe operation that was performed.
IBANK dataThe data that was read.

The battery payload

VoltageEventArgs carries the battery voltage in millivolts.

HotKeyEventArgs carries the key that was pressed and whether it went down or up.

See Events in the API reference for the full definition of the payload types.
