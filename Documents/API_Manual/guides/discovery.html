Device discovery

Finding a reader over Bluetooth LE or over TCP/IP.

Bluetooth LE

The Bluetooth LE discovery uses DeviceFinder. The search runs in the background and reports every reader it finds.

using CSLibrary;
using Plugin.BLE.Abstractions;
using Plugin.BLE.Abstractions.Contracts;

DeviceFinder.Initialize(adapter, bluetoothLe);

DeviceFinder.OnDeviceFound += (sender, e) =>
{
    DeviceInformation device = e.Device;
    Console.WriteLine($"{device.Name}  {device.Rssi} dBm  {device.DeviceType}");
};

DeviceFinder.OnSearchCompleted += (sender, e) =>
{
    if (e.TimedOut)
        Console.WriteLine("The search finished because of the timeout.");
};

DeviceFinder.StartDeviceSearch(ScanMode.LowLatency, 5000);

// ... later ...
DeviceFinder.StopDeviceSearch();

The device information

MemberDescription
string IdThe platform identifier of the device.
string NameThe friendly name of the device.
RFIDDEVICE.MODEL DeviceTypeThe reader model that the name identifies.
int RssiThe signal strength of the advertisement that the reader was found with.
IDevice NativeDeviceThe underlying platform device, used when connecting.

TCP/IP

A fixed reader announces itself with a UDP broadcast. NetFinder collects the announcements.

using CSLibrary.NetFinder;

NetFinder.OnSearchCompleted += (sender, e) =>
{
    Console.WriteLine($"{e.DeviceName}  {e.IPAddress}  {e.Port}");
};

NetFinder.SearchDevice();

// ... later ...
NetFinder.StopSearch();

The device information

MemberDescription
string IPAddressThe IP address that the reader announced.
string MacAddressThe MAC address of the reader.
string DeviceNameThe friendly name of the reader.
ushort PortThe TCP port that the reader listens on.

The search methods are static. NetFinder.Devices holds the readers that were found so far and NetFinder.ClearDeviceList() empties it.
