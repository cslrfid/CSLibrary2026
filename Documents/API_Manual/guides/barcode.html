Barcode scanner

The barcode scanner of the readers that have one.

Reading a barcode

reader.barcode.OnCapturedNotify += (sender, e) =>
{
    Console.WriteLine($"Barcode: {e.Barcode}");
};

reader.barcode.Start();

The scanner is stopped with reader.barcode.Stop().

The scanner state

reader.barcode.state reports whether the scanner is running.

ValueDescription
STATE.UNKNOWNThe state of the scanner is not known.
STATE.IDLEThe scanner is ready.
STATE.BUSYThe scanner is reading a barcode.

The scanner options

reader.barcode.FastBarcodeMode(true);

The buzzer and the vibrator

reader.barcode.VibratorOn(VIBRATORMODE.SHORT, 200);
reader.barcode.VibratorOff();

Only the readers with an integrated scanner support this subsystem. On the other readers the calls return false and no barcode is ever delivered.

See Barcode scanner in the API reference.
