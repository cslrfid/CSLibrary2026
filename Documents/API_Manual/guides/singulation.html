Singulation

Choosing how the reader separates the tags that it reads.

The singulation algorithm

reader.rfid.SetCurrentSingulationAlgorithm(SingulationAlgorithm.FIXEDQ);
AlgorithmDescription
SingulationAlgorithm.FIXEDQAlways uses the same Q value. The simplest and the fastest mode.
SingulationAlgorithm.DYNAMICQAdjusts the Q value while the inventory runs, so that the number of tags per read stays constant.

The fixed Q algorithm

reader.rfid.SetFixedQParms(new FixedQParms
{
    qValue = 4,
    retryCount = 0,
    toggleTarget = 0,
    repeatUntilNoTags = 0
});

The Q value is the number of bits that the reader sends in the query. A low value reads many tags at once, a high value reads fewer tags but reads them faster.

The dynamic Q algorithm

reader.rfid.SetDynamicQParms(new DynamicQParms
{
    startQValue = 4,
    minQValue = 0,
    maxQValue = 15,
    toggleTarget = 0
});

The tag group

The tags can be split into groups, and an operation can be applied to one group only.

reader.rfid.SetTagGroup(TagGroup.SL_ALL);

The RSSI filter

The reader can ignore the tags that are too weak to be useful. The threshold is given in dBuV or in dBm.

reader.rfid.SetRSSIFilter(RSSIFILTERTYPE.ENABLE);
reader.rfid.SetRSSIdBmFilter(RSSIFILTERTYPE.ENABLE, RSSIFILTEROPTION.GREATER_THAN, -60);

See Singulation in the API reference and Constants and enumerations for the enumeration values.
