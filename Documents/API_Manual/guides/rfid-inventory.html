CSLibrary2026 API Reference

Running an inventory

Reading the tags that are in range of the reader.

Starting the inventory

reader.rfid.StartOperation(Operation.TAG_RANGING);

The inventory runs until it is stopped, until the inventory duration elapses or until the reader is disconnected.

reader.rfid.StopOperation();

The operations

OperationDescription
Operation.TAG_RANGINGReads the tags that are in range.
Operation.TAG_SEARCHINGReads the tags that match the selection criteria.
Operation.TAG_READReads the memory of the target tag.
Operation.TAG_WRITEWrites the memory of the target tag.
Operation.TAG_LOCKLocks the target tag.
Operation.TAG_KILLKills the target tag.

The inventory options

The options of the radio are held in reader.rfid.Options. They must be set before the operation is started.

CSLibraryOperationParms options = reader.rfid.Options;

options.TagRanging.Multibanks = 2;
options.TagRanging.Bank1 = MemoryBank.USER;
options.TagRanging.Offset1 = 0;
options.TagRanging.Count1 = 1;
options.TagRanging.Bank2 = MemoryBank.EPC;
options.TagRanging.Offset2 = 0;
options.TagRanging.Count2 = 2;

The inventory duration

The inventory can be limited to a number of milliseconds.

reader.rfid.SetInventoryDuration(1000);        // every antenna port
reader.rfid.SetInventoryDuration(1000, 0);     // antenna port 0 only

The inventory callback

Every tag that the reader reads is delivered through OnAsyncCallback.

reader.rfid.OnAsyncCallback += (sender, e) =>
{
    if (e.type != CallbackType.TAG_RANGING)
        return;

    TagCallbackInfo tag = e.info;

    string epc = tag.epc.epcString;
    string tid = tag.TID.TIDString;
    float rssi = tag.rssi;
    uint port = tag.antennaPort;
    uint channel = tag.freqChannel;

    Console.WriteLine($"{epc}  {rssi} dBm  port {port}");
};

See Event reference for every field of the callback payload.

The tag rate

The reader reports how many tags it reads per second.

reader.rfid.OnInventoryTagRateCallback += (sender, e) =>
{
    Console.WriteLine($"{e.inventoryTagRate} tags per second");
};

Reading the memory of a tag

The inventory callback also carries the memory banks that were requested. The bank data is in Bank1Data, Bank2Data and Bank3Data.

if (tag.Bank1Data != null && tag.Bank1Data.Length > 0)
{
    Console.WriteLine($"USER bank: {tag.Bank1Data.Length} words");
}

The callback is raised on a background thread. Keep the work in the handler short and move anything slow to your own thread.
