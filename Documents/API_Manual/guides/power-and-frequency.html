CSLibrary2026 API Reference

Power and frequency

The output power of the reader and the regulatory region it operates in.

The output power

The power is given in tenths of a decibel milliwatt: 300 means 30.0 dBm.

reader.rfid.SetPowerLevel(300);        // 30.0 dBm
reader.rfid.SetPowerLevel(300, 0);     // antenna port 0 only

// A different power for every antenna port.
reader.rfid.SetPowerLevel(new uint[] { 300, 250, 250 });

GetActiveMaxPowerLevel() returns the highest power that the current region allows.

The power boost

reader.rfid.SetPowerBoost(true);

The country and the region

The reader must only operate in the region that the tags of the country use.

// By country name.
reader.rfid.SetCountry("USA");

// By country name and, for a fixed channel country, the channel.
reader.rfid.SetCountry("USA", 0);

The countries that the connected reader supports are listed by GetActiveCountryNameList(), and the current country is returned by GetCurrentCountry().

The link profile

A link profile groups the settings that the reader uses in one regulatory region. The profiles that the reader supports in the current country are returned by GetActiveLinkProfileName().

uint[] profiles = reader.rfid.GetActiveLinkProfile();
string[] names = reader.rfid.GetActiveLinkProfileName();

reader.rfid.SetCurrentLinkProfile(profiles[0]);

The frequency channel

// A fixed channel.
reader.rfid.SetFixedChannel(RegionCode.FCC, 0);

// Frequency hopping.
reader.rfid.SetHoppingChannels(RegionCode.FCC);

The noise floor

decimal noiseFloor = reader.rfid.GetNoiseFloor();

See Power, frequency and country in the API reference.
