CSLibrary2026 API Reference

Device discovery

Finding a reader over Bluetooth LE or TCP/IP.

DeviceFinder

NamespaceCSLibrary
Kindclass
Base typeobject
Obtainnew DeviceFinder()

Discovers the CSL RFID readers that advertise over Bluetooth Low Energy.

Call DeviceFinder.Initialize with the Plugin.BLE adapter before calling DeviceFinder.StartDeviceSearch, then handle DeviceFinder.OnDeviceFound and DeviceFinder.OnSearchCompleted to collect the readers and to connect to them.
