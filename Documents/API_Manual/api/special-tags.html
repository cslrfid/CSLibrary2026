CSLibrary2026 API Reference

Special tag modules

The FM13DT160 and EM4325 passive sensor modules.

ClassEM4325

NamespaceCSLibrary
Kindclass
Base typeobject
Obtainreader.rfid.EM4325

Provides access to the EM4325 passive sensor module built into the reader.

The instance is reached through RFIDReader.EM4325; the parameters of a request are set in ClassEM4325.Options before the operation is started.

MemberDescription
EM4325Paras Options;

Represents the parameters of the EM4325 module operations.

Set the parameters before calling ClassEM4325.StartOperation and read the results from the same object once the operation has completed.

event EventHandler<OnAccessCompletedEventArgs> OnAccessCompleted

Occurs when an EM4325 module operation has completed.

The event argument tells which operation has finished and whether it succeeded; the measurement itself is read back from ClassEM4325.Options.

void ClearEventHandler()

Removes all subscribers of the ClassEM4325.OnAccessCompleted event.

int StartOperation(Operation operation)

Starts the given operation on the EM4325 sensor module.

ParameterTypeDescription
operationOperationThe operation to run.

Returns 0 when the operation has been started, -1 when the operation is not supported.

The operation runs asynchronously and its result is reported through the ClassEM4325.OnAccessCompleted event.

Operation

NamespaceCSLibrary
Kindenum
Base typeEnum
ImplementsIComparable, IConvertible, IFormattable, ISpanFormattable

Defines the operations that can be performed on the FM13DT160 tag.

MemberDescription
READMEMORY = 0

Reads a block of memory from the tag.

WRITEMEMORY = 1

Writes a block of memory to the tag.

READREGISTER = 2

Reads a configuration register of the tag.

WRITEREGISTER = 3

Writes a configuration register of the tag.

AUTH = 4

Authenticates the tag so that its protected content can be accessed.

GETTEMP = 5

Reads the temperature measured by the tag.

STARTLOG = 6

Starts the logging of the sensor measurements in the memory of the tag.

STOPLOG = 7

Stops the logging of the sensor measurements in the memory of the tag.

DEEPSLEEP = 8

Puts the tag into its deep sleep mode.

OPMODECHK = 9

Reads the operating mode status of the tag.

INITIALREGFILE = 10

Initializes the register file of the tag.

LEDCTRL = 11

Turns the LED of the tag on for one second.
