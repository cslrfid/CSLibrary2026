CSLibrary2026 API Reference

Reader and connection

The entry point of the library and the connection to a reader.

HighLevelInterface

NamespaceCSLibrary
Kindclass
Base typeobject
Obtainnew HighLevelInterface()

Entry point of the CSL RFID reader library.

An instance represents one reader connection. Create an instance, attach it to a reader over Bluetooth LE or TCP/IP, then drive the reader through the subsystem properties: HighLevelInterface.rfid, HighLevelInterface.barcode, HighLevelInterface.notification, HighLevelInterface.battery, HighLevelInterface.bluetoothIC and HighLevelInterface.siliconlabIC.

event Action<ConnectionStatus> ConnectionStatusChanged

Occurs when the state of the TCP/IP connection changes.

The argument is a CSLTCPSTREAM.ConnectionStatus value that describes the new state, for example Connected, Disconnected or Reconnecting; the handler is attached to the underlying TCP stream only when it exists, so the event must be subscribed after the first connection.

void DisconnectAsync()

Unified disconnect — routes to BLE or TCP implementation based on current connection mode.

The unified API is deliberately void: the BLE and TCP implementations are selected internally, so the caller cannot tell (and does not need to know) which transport is in use. Note that this differs from the previous CSLibrary2026 implementation, where the HAL exposed public async Task<bool> DisconnectAsync(); applications written against that version have to drop the _ = discard (reader.DisconnectAsync();).

Task<bool> ConnectAsync(string ipAddress, int port)

Connects to a reader over TCP/IP.

ParameterTypeDescription
ipAddressstringThe IP address of the reader.
portintThe TCP port the reader listens on.

Returns true when the connection has been established, false when it failed.

When the call returns true the reader is initialized and the RFID, barcode and notification subsystems are ready to be used; the connection is closed with HighLevelInterface.TCP_DisconnectAsync.

Task ReconnectAsync()

Reconnects to the reader over TCP/IP after the connection has been lost.

The IP address and port of the previous connection are reused and the connection is retried up to ten times with a one second delay; the call does nothing when the reader has never been connected.

void TCP_DisconnectAsync()

Closes the TCP/IP connection to the reader.

The transport is released and the common disconnect handling is executed, so the reader is no longer usable until HighLevelInterface.ConnectAsync is called again.
