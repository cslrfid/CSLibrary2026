CSLibrary2026 API Reference

Notification, battery and hardware

Battery level, hardware keys and the reader hardware information.

Battery

NamespaceCSLibrary
Kindclass
Base typeobject
Obtainreader.battery

Provides the battery information of the connected reader.

The instance is reached through HighLevelInterface.battery.

MemberDescription
bool GetCurrentAutoBattryStatus()

Gets the state of the automatic battery level reporting.

Returns true when the reader reports its battery level on its own, false otherwise.

The library does not currently switch the automatic reporting on, so the returned value is always false.

void SetPollingTime(uint sec)

Sets the interval at which the battery voltage of the reader is polled.

ParameterTypeDescription
secuintThe polling interval in seconds; 0 disables the polling. The default interval is 300 seconds.

BluetoothIC

NamespaceCSLibrary
Kindclass
Base typeobject
Obtainreader.bluetoothIC

Provides access to the Bluetooth controller of the connected reader.

The instance is reached through HighLevelInterface.bluetoothIC.

MemberDescription
uint GetFirmwareVersion()

Gets the firmware version of the Bluetooth controller of the reader.

Returns The firmware version as a 24-bit value, or 0 when the reader did not report one.

string GetDeviceName()

Gets the Bluetooth device name of the reader.

Returns The device name, or null when the reader has not reported it yet.

bool SetDeviceName(string deviceName)

Sets the Bluetooth device name of the reader.

ParameterTypeDescription
deviceNamestringThe new device name; it must not be longer than 20 characters.

Returns true when the name has been sent to the reader, false when the name is longer than 20 characters.

Notification

NamespaceCSLibrary
Kindclass
Base typeobject
Obtainreader.notification

Provides the notifications reported by the reader, such as the battery voltage and the state of the hardware key.

The instance is reached through HighLevelInterface.notification.

MemberDescription
byte[] STARTAUTOREIGGERREPORTING;static

Represents the command that starts the automatic reporting of the hardware key state.

The command carries the reporting interval in seconds as payload; the stop command switches the reporting off.

byte[] STOPAUTOREIGGERREPORTING;static

Represents the command that stops the automatic reporting of the hardware key state.

event EventHandler<VoltageEventArgs> OnVoltageEvent

Occurs when the reader reports its battery voltage.

The event argument is a Notification.VoltageEventArgs whose VoltageEventArgs.Voltage property holds the measured voltage in millivolts.

event EventHandler<HotKeyEventArgs> OnKeyEvent

Occurs when the hardware key of the reader is pressed or released.

The event argument is a Notification.HotKeyEventArgs that identifies the key and tells whether it has been pressed or released.

uint GetCurrentBatteryLevel()

Gets the last battery voltage reported by the reader.

Returns The battery voltage in millivolts, or 0 when no voltage has been reported yet.

void SetTriggerReleaseAbortRFID(bool enable)

Configures whether the reader aborts the running RFID inventory when the trigger is released.

ParameterTypeDescription
enablebooltrue to abort the inventory on trigger release, false to let it run until it is stopped.
void ClearEventHandler()

Removes all subscribers of the Notification.OnVoltageEvent and Notification.OnKeyEvent events.

SiliconLabIC

NamespaceCSLibrary
Kindclass
Base typeobject
Obtainreader.siliconlabIC

Provides access to the Silicon Labs microcontroller of the connected reader.

The instance is reached through HighLevelInterface.siliconlabIC.

MemberDescription
bool _firmwareOlderT108;

Represents whether the reader runs a firmware older than version 1.0.0.8, as detected during the connection sequence.

event EventHandler<OnAccessCompletedEventArgs> OnAccessCompleted

Occurs when the reader reports the result of an access command.

The event argument carries the reported information, which is the serial number of the reader, and the kind of information it is.

uint GetFirmwareVersion()

Gets the firmware version of the Silicon Labs microcontroller of the reader.

Returns The firmware version as a 24-bit value, or 0 when the reader did not report one.

void GetSerialNumber()

Raises the SiliconLabIC.OnAccessCompleted event with the serial number of the reader.

Use SiliconLabIC.GetSerialNumberSync to obtain the serial number directly.

string GetSerialNumberSync()

Gets the serial number of the reader.

Returns The serial number reported by the reader, or null when it has not been received yet.

string GetPCBVersion()

Gets the PCB version of the reader.

Returns The PCB version reported by the reader, or null when it has not been received yet.

void ClearEventHandler()

Removes all subscribers of the SiliconLabIC.OnAccessCompleted event.
