SelectMask

NamespaceCSLibrary.Structures
Kindclass
Base typeobject

The tag mask is used to specify a bit pattern that is used to match against one of a tag's memory banks to determine if it is matching or non-matching. A mask is a combination of a memory bank and a sequence of bits that will be matched at the specified offset within the chosen memory bank.

MemberDescription
SelectMask()

Constructor

SelectMask(MemoryBank bank, uint offset, uint count, byte[] epc)

Custom constructor

ParameterTypeDescription
bankMemoryBankMemory bank
offsetuintoffset in bit
countuintcount in bit
epcbyte[]epc mask
byte[] mask { get; set; }

A buffer that contains a left-justified bit array that represents that bit pattern to match – i.e., the most significant bit of the bit array appears in the most-significant bit (i.e., bit 7) of the first byte of the buffer (i.e., mask[0]). All bits beyond count are ignored. For example, if the application wished to find tags with the following 12 bits 1000.1100.1101, starting at offset 16 in the EPC memory bank, then the fields would be set as follows: bank = RFID_18K6C_MEMORY_BANK_EPC offset = 16 count = 12 mask[0] = 0x8C (1000.1100) mask[1] = 0xD? (1101.????)

MemoryBank bank;

The memory bank that contains the bits that will be compared against the bit pattern specified in mask. For a tag mask, MemoryBank.RESERVED is not a valid value.

uint offset;

The offset, in bits, from the start of the memory bank, of the first bit that will be matched against the mask. If offset falls beyond the end of the memory bank, the tag is considered non-matching.

uint count;

The number of bits in the mask. A length of zero will cause all tags to match. If (offset+count) falls beyond the end of the memory bank, the tag is considered non-matching. Valid values are 0 to 255, inclusive.

SingulationMask

NamespaceCSLibrary.Structures
Kindclass
Base typeobject

The post-singulation match mask is used to specify a bit pattern of up to 496 bits that is used to match against the EPC backscattered by a tag during singulation to determine if a tag is matching or non-matching.

MemberDescription
SingulationMask()

Constructor

SingulationMask(uint offset, uint count, byte[] mask)

Constructor

ParameterTypeDescription
offsetuint
countuint
maskbyte[]
byte[] mask { get; set; }

A buffer that contains a left-justified bit array that represents that bit pattern to match – i.e., the most significant bit of the bit array appears in the most-significant bit (i.e., bit 7) of the first byte of the buffer (i.e., mask[0]). All bits beyond count are ignored. For example, if the application wished to find tags with the following 16 bits 1011.1111.1010.0101, starting at offset 20 in the Electronic Product Code, then the fields would be set as follows: offset = 20 count = 16 mask[0] = 0xBF (1011.1111) mask[1] = 0xA5 (1010.0101)

uint offset;

The offset in bits, from the start of the Electronic Product Code (EPC), of the first bit that will be matched against the mask. If offset falls beyond the end of EPC, the tag is considered non-matching.

uint count;

The number of bits in the mask. A length of zero will cause all tags to match. If (offset+count) falls beyond the end of the EPC, the tag is considered non-matching. Valid values are 0 to 496, inclusive.
