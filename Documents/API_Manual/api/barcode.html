BarcodeReader

NamespaceCSLibrary
Kindclass
Base typeobject
Obtainreader.barcode

Provides access to the barcode scanner of a CSL reader equipped with an integrated scanner module.

The instance is reached through HighLevelInterface.barcode; readers without a scanner module simply never report a ready scanner.

MemberDescription
STATE state { get; }

Gets the current state of the barcode scanner module.

string _SN;

Represents the serial number reported by the barcode scanner module.

The value is null until the reader answers the serial number query sent during the hardware check.

string _ESN;

Represents the equipment serial number reported by the barcode scanner module.

The value is null until the reader answers the ESN query sent during the hardware check.

string _Prefix;

Represents the prefix configured in the barcode scanner module as a space separated hexadecimal string.

string _Suffix;

Represents the suffix configured in the barcode scanner module as a space separated hexadecimal string.

event EventHandler<BarcodeEventArgs> OnCapturedNotify

Occurs when the barcode scanner has decoded a barcode.

The event argument is a Barcode.BarcodeEventArgs whose BarcodeEventArgs.MessageType is DEC_MSG and whose message carries the decoded text in DecodeMessage.pchMessage.

void ClearEventHandler()

Removes all subscribers of the BarcodeReader.OnCapturedNotify event.

bool Start()

Start to capture barcode, until stop is sent.

bool Stop()

Stop capturing

bool VibratorOn()

Switches the vibration motor of the reader on.

Returns true when the command has been sent to the reader.

bool VibratorOn(VIBRATORMODE mode, uint time)

Switches the vibration motor of the reader on for a limited time.

ParameterTypeDescription
modeVIBRATORMODEThe event that triggers the vibration motor, see BarcodeReader.VIBRATORMODE.
timeuintThe vibration duration, sent to the reader as a 16-bit big-endian value.

Returns true when the command has been sent to the reader.

bool VibratorOff()

Switches the vibration motor of the reader off.

Returns true when the command has been sent to the reader.

bool FastBarcodeMode(bool enable)

Enables or disables the fast barcode scanning mode of the scanner module.

ParameterTypeDescription
enablebooltrue to enable fast scanning, false to return to the normal scanning mode.

Returns true when the command has been sent to the reader, false when the scanner module is not available.

void FactoryReset()

Restores the barcode scanner module to its factory default settings.

The module is re-programmed with the factory trigger mode, data formats and prefix and suffix settings; the command is skipped when the scanner module is not available.
